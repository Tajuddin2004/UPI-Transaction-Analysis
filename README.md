# UPI Transaction Analysis Dashboard

An interactive Power BI dashboard developed to analyze UPI transaction
patterns, transaction amounts, bank performance, payment methods,
customer demographics, merchants, transaction status, and geographical trends.

## Dashboard Preview

![UPI Transaction Dashboard](UPI-Transaction-Analysis/Dashboard UPI.png)

## Project Overview

This project focuses on analyzing UPI transaction data using Microsoft
Power BI to identify transaction trends, customer behavior, payment
patterns, and banking activity.

The dashboard provides interactive visualizations and filters that allow
users to explore transaction performance across different dimensions.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset

The dataset contains **20,000 UPI transaction records** with information
related to transactions, customers, banks, merchants, payment methods,
devices, cities, and transaction status.

## Dashboard Features

### Transaction Analysis
Analyze transaction volume, transaction amount, and transaction status
to understand overall UPI transaction performance.

### Banking Analysis
Compare transactions between sending and receiving banks to identify
bank-wise transaction patterns.

### Customer Analysis
Explore transaction behavior based on customer age, gender, and location.

### Payment Analysis
Analyze different payment methods, payment modes, and device types
used for transactions.

### Merchant Analysis
Identify transaction patterns across different merchants and purposes.

### Geographical Analysis
Analyze transaction activity across different cities.

### Time-Based Analysis
Explore transaction trends based on transaction dates and times.
